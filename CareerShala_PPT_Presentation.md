## SLIDE 5: Core Innovation 2 — LangGraph Agentic Workflows

### 🖥️ **Visual Layout:**
*Horizontal flow graph showing state machine nodes and retry loop.*

---

### 🤖 **Stateful Multi-Agent Workflows (Zero Hallucination)**

```
 [User Resume + JD] ──► (Node 1: JD Analyzer) ──► (Node 2: Draft Generation)
                                                          │
 [Success Output] ◄─── (Node 4: Auto-Retry Loop) ◄─── (Node 3: Quality Check)
```

#### 🛡️ **Engineered AI Guardrails:**
* **Verbatim Bullet Restoration:** A post-LLM Python pass compares enhanced resumes with original text, preserving work experience bullets verbatim to prevent model hallucination.
* **Placeholder Auto-Retry:** If the Quality Validator detects residual placeholders (`[Insert Company]`), it automatically rejects the output and triggers a corrective retry loop.
* **5-Tier Fallback Pool:** Multi-key rotation across **Groq ➔ Gemini 2.5 ➔ Mistral ➔ Anthropic ➔ Local Templates** ensures **99.9% uptime**.

---

🗣️ **Speaker Script (Say This):**
> *"Instead of basic prompts, we use LangGraph state graphs. If our Quality Validator node finds unfilled placeholders, it automatically re-runs the node. Plus, our bullet restoration engine ensures the AI never hallucinates or changes original job achievements."*
